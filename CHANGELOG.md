# Changelog

Every release of int-positron-config (the CHANWE theme). Each one is a git tag `vX.Y.Z` with a GitHub release
carrying `int-positron-config-vX.Y.Z.zip` (the whole repository) and `chanwe-obsidian-X.Y.Z.vsix`.

## Unreleased

- Versioning and release script documented (`scripts/release.sh`).

## 0.5.3 - 2026-10-11

- Unified window bars, activity bar, sidebar and embedded chat on the intermediate obsidian (`#202630`); white
  text on orange buttons and badges; better title, selection, comment and link contrast; explicit colours for
  Positron data tools. The whole-repository zip was added to this release on 2026-10-11.
