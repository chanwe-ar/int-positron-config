# int-positron-config

A reproducible snapshot of the user-level Positron configuration (settings, shortcuts, extensions) and the
**Chanwe Obsidian** theme. Read `README.md` first.

## Rules

- Never commit credentials, tokens, connection files or workspace state; settings may only point at local paths.
- The theme is generated by `themes/chanwe-obsidian/build.mjs`; change the palette map there, not the JSON by hand.

## Versioning and releases

This repo is a versioned asset of the CHANWE suite: CHANWE Espacios (desktop, and later mobile) ships a
pinned release of it in its downloads menu as the CHANWE theme. A change reaches people only through a release.

- Versions are `vMAJOR.MINOR.PATCH`, the `version` of `themes/chanwe-obsidian/package.json`: PATCH for fixes,
  MINOR for theme or configuration changes, MAJOR when a setting or shortcut people rely on is removed or renamed.
- Record every change under `## Unreleased` in `CHANGELOG.md`.
- To release, on an up-to-date `main`: move the Unreleased notes under `## X.Y.Z - YYYY-MM-DD`, set the theme's
  version, merge, then run `scripts/release.sh X.Y.Z`. It tags `vX.Y.Z` and publishes a GitHub release with
  `int-positron-config-vX.Y.Z.zip` (the whole repository) and `chanwe-obsidian-X.Y.Z.vsix`.
- Never move or delete a published tag or release; fix forward with a new version.
- Then raise the pin in chanwe-desktop-app `components.lock.json`; the next desktop release carries it.
